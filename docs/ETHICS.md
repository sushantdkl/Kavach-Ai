# Ethics boundary

All identities, balances and transaction receipts are synthetic. No real payment
occurs. Only the explicitly created local Kavach testbed may receive workloads.
Private addressing alone is insufficient proof of an authorized destination.
Host smoke tools accept a literal loopback target and disable redirects/proxies.
Later cluster load tools must verify the named cluster and service identity.

No external payment providers, real credentials, exploit payloads, scanning or
malicious protocol behavior. Attack-like means only a bounded request-rate
schedule. Set and enforce the ceiling before load begins. Preserve failed and
invalid runs with reasons. Logs must not contain user secrets or financial data.
